# 모이다 수익화 전략

## 좁고 강한 초기 시장

첫 구매자는 `5~20명 규모의 오프라인 프로젝트팀을 반복 운영하는 교육기관·부트캠프·에이전시`로 정의한다. 범용 회의록보다 “공유 화면에서 합의하고 승인한 일만 보드로 넘긴다”는 운영 문제를 판다.

## 가격 가설

| 플랜 | 월 가격 | 포함 | 전환 장치 |
| --- | ---: | --- | --- |
| Starter | 무료 | 팀 1개, 월 5회, 기본 산출물 | 실제 회의에서 가치 확인 |
| Team | 좌석당 12,000원, 최소 3석 | 무제한 회의, 결정 이력, 업무 분배, 내보내기 | 14일 체험 후 결제 |
| Program | 월 290,000원부터 | 여러 팀, 운영 대시보드, 템플릿, 온보딩 | 교육기관·에이전시 계약 |
| Enterprise | 협의 | SSO, 보존 정책, BYOK, 감사 로그 | 보안 검토 기반 연간 계약 |

경쟁사의 좌석당 약 $10~30 구간보다 초기 진입 가격은 낮추되, 녹취 저장 공간을 팔지 않기 때문에 원가와 프라이버시 포지션을 함께 지킨다. 사용량 초과 과금보다 좌석 기반의 예측 가능한 가격을 우선한다.

## 수익 루프

1. 무료 파일럿에서 `승인된 할 일 비율`, `미배정 해소 시간`, `후속 완료율`을 측정한다.
2. 회의 종료 직후 “이번 회의에서 N개의 실행 누락을 막았습니다”라는 가치 영수증을 보여준다.
3. 5번째 회의 또는 두 번째 팀 생성 시 Team 체험을 제안한다.
4. 3개 이상 팀을 운영하는 계정에는 Program 플랜 상담을 제안한다.
5. 결제 실패·해지 시 원문이 아니라 승인 산출물을 내보낼 수 있게 해 신뢰를 유지한다.

## 과금 구현 순서

- Stripe Checkout에서 정액 구독을 만든다.
- 웹훅 서명을 검증하고 구독 상태를 `billing_subscriptions`에 멱등 upsert한다.
- 제품 권한은 Checkout 성공 리다이렉트가 아니라 웹훅의 구독 상태로 부여한다.
- 좌석 변경은 Stripe 수량과 팀원 수를 동기화한다.
- 한국 사업자는 실제 판매 전 세금계산서·부가세·환불 약관·개인정보 처리방침을 검토한다.

## 실험 백로그

| 실험 | 성공 기준 | 중단 기준 |
| --- | --- | --- |
| 교육팀 10곳 2주 파일럿 | 6곳이 주 2회 이상 사용 | 주 1회 미만 70% |
| 가치 영수증 | 체험 전환 +20% | 유의미한 차이 없음 |
| 12,000원/석 가격 | 유료 의향 30% 이상 | 10% 미만 |
| 공유 화면 전용 포지셔닝 | 인터뷰 60%가 차별점으로 회상 | 25% 미만 |
