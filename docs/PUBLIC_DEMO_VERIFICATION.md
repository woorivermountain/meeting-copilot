## 운영 범위와 남은 검증

현재는 공개 체험용 프리릴리스다. 실제 마이크의 장시간 회의, 화자 분리, 잡음·고유명사 인식 품질, 다수 사용자의 동시 부하, 복구·백업 운영은 이 검사에서 다루지 않았다. 자료 검색은 키워드 방식이며 웹 검색이나 벡터 검색이 아니다.

Render 무료 웹 서비스는 유휴 상태에서 중지되므로 첫 접속에 1분 이상 걸릴 수 있다. 무료 PostgreSQL은 생성 후 30일 만료되므로 지속 제공하려면 만료 전에 데이터와 호스팅을 이전하거나 유료 전환해야 한다. 현재 DB는 2026년 10월 20일 생성했다. 세션·AI 임시 작업은 서버 메모리에 있어 재시작 후 재로그인이 필요하며 임시 질문·답변은 보존되지 않는다. PostgreSQL에 저장한 전사와 확정 항목은 별도다.

외부 호출은 서비스 전체에서 UTC 일자별 LLM 40회·음성 전사 100회로 제한한다. 자료함 질의는 한 번에 여러 LLM 호출을 사용할 수 있고, 실패한 외부 호출도 상한에 포함한다. 이는 달러 단위 비용 보장이 아니다. 키는 Render 환경변수에만 등록했으며 저장소·이미지에 포함하지 않았다. 체험에는 민감한 실제 회의 대신 예문을 사용한다.
