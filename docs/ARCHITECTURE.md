# 에이전트 하네스와 루프 설계

`MeetingAgentHarness`는 프롬프트 모음이 아니라 실행 정책이다.

1. 브라우저 정규식이 명시적 호출만 통과시킨다.
2. `gpt-5.6-luna`가 요청 의도·지시대명사·근거 구간을 선택한다.
3. 단순 요청은 저지연 모델에서 끝내고, 상충 검토·계산·중요 의사결정만 `gpt-5.6-sol`로 승격한다.
4. 모든 결과는 Zod/JSON Schema를 통과해야 한다.
5. 원문에 없는 근거, 낮은 신뢰도, 명단 밖 담당자는 서버가 제거한다.
6. 실패는 빈 후보와 `retryable` 상태로 축소되며 회의를 멈추지 않는다.

종료 루프는 `추출 → 명단 검증 → 사용자 수정·제외 → 승인 저장`이다. 미승인 후보와 전사 원문은 DB에 들어갈 수 없도록 스키마에서 경로를 제거했다.

## 운영 품질 루프

내용 없이 지표만 수집한다: 호출 지연, 토큰, 추정 비용, 카드 제거율, 후보 수정·제외율. 고정 평가 세트를 매 배포 전에 실행하고, `근거성 100%`, `명단 외 담당자 0건`, `일반 발화 호출 0건`을 릴리스 게이트로 둔다.
