# 무엇을 평가했고, 무엇은 아직 모르는가

모이다의 고정 평가는 모델의 말투나 요약 취향을 채점하지 않습니다. 회의 AI가 넘지 않아야 할 경계가 코드 변경 뒤에도 유지되는지를 확인합니다.

## 평가 구성

`tests/evals.test.ts`는 외부 API를 호출하지 않는 결정론적 provider를 사용합니다. 라우터와 생성기가 일부러 잘못된 후보를 반환하게 한 뒤, 서버의 `MeetingAgentHarness`가 이를 차단하는지 검사합니다.

| 범주 | 확인하는 실패 | 기대 동작 |
| --- | --- | --- |
| 근거 | 라우터·생성기가 원문에 없는 문장을 근거로 반환 | 카드 제거 |
| 신뢰도 | confidence가 55 미만인 후보 반환 | 카드 제거 |
| 모델 승격 | 상충 검토를 단순 요청으로 처리 | reasoning worker로 승격 |
| 차트 | 원문에 없는 항목명·수치를 시각화 | 카드 제거 |
| 담당자 | 참여자 명단에 없는 이름을 할 일에 배정 | 담당자를 빈 값으로 변경 |
| 빈 결과 | 근거 있는 답을 만들 수 없음 | 억지로 생성하지 않고 빈 배열 유지 |
| 사용량 | 라우팅과 생성 호출의 토큰 누락 | 두 호출 사용량 합산 |

현재 고정 평가는 12개이며, 호출 조건과 데이터 계약을 포함한 전체 회귀 테스트는 20개입니다.

```bash
npm run eval       # Agent 경계 12개
npm test           # 전체 20개
npm run typecheck
npm run build
```

## 이 숫자의 의미

12/12는 미리 정의한 실패 사례를 현재 코드가 모두 막았다는 뜻입니다. 실제 회의에서 답변 정확도가 100%라는 뜻은 아닙니다. 외부 모델을 고정하지 않았기 때문에 provider의 성능 평가와도 다릅니다.

실제 도입 전에는 별도로 다음을 확인해야 합니다.

- 한국어 회의 전사 오류가 근거 선택에 미치는 영향
- 팀별 표현과 이름에서 발생하는 누락·오탐
- 모델·프롬프트 버전별 품질과 지연 변화
- 사용자가 후보를 수정·제외하는 비율과 후속 완료율
- 공급자 보존 정책과 조직별 보안 요구

고정 평가는 출시 전 안전망이고, 사용자 성과의 대체물이 아닙니다.
