# Groq Whisper 전사 · DeepSeek 회의 AI 연결

## 구성

- 음성 전사: Groq의 **whisper-large-v3-turbo**. 선택한 마이크에서 최대 약 4초 단위로 수집한 WAV를 서버가 중계합니다. 발화 후 약 600ms 정적 시 조기 분할하되 요청 시작 간격은 최소 4초입니다. 한국어 전사(`language=ko`)이며 영어 번역 API는 사용하지 않습니다. 단어별 실시간 표시가 아니며, 수집·대기·API 처리 시간이 걸립니다. 구간 경계에서 문장이 끊길 수 있어 실제 회의 검증이 필요합니다.
- 회의 AI: DeepSeek API. 질문과 선택한 대화, 접근 권한이 있는 문서 발췌문을 전달합니다. 대화 전체를 매번 보내는 구조는 아닙니다. 요약 요청은 저장된 전사 버전을 대상으로 합니다.
- 전사 동의와 AI 분석 동의는 별개입니다. 자료함의 읽기 권한은 서버가 검증하고, 회의 답변에는 팀 전체 공유 자료만 사용합니다.

## 설정 순서

1. [Groq 콘솔](https://console.groq.com/keys)에서 API 키를 발급받습니다. 계정이 Free 플랜인지, Whisper 모델을 사용할 수 있는지 확인합니다.
2. 회의 음성을 처리하기 전에 콘솔의 Data Controls에서 보관 설정을 확인합니다. 필요한 경우 Zero Data Retention을 활성화합니다. 앱이 해당 계정 설정을 대신 바꾸지는 않습니다.
3. 프로젝트 루트 `.env.service`에 아래 두 값을 직접 입력합니다. 이 파일은 Git 추적 대상에서 제외되어 있습니다. 키를 채팅에 보내지 마세요.
   - `GROQ_API_KEY`
   - `DEEPSEEK_API_KEY`
4. `STT_PROVIDER=groq`, `GROQ_STT_MODEL=whisper-large-v3-turbo`, `LLM_PROVIDER=deepseek`를 유지합니다. Groq 모델은 `whisper-large-v3`로도 변경할 수 있습니다. `DEEPSEEK_MODEL`은 계정에서 이용 가능한 모델로 변경할 수 있습니다.
5. 저장하지 않은 회의 내용을 정리한 뒤 서비스 서버를 재시작합니다. 실행 스크립트 `npm run dev`가 이 파일을 읽습니다. 키는 프런트 개발 서버 환경에서 제외됩니다.

## 무료 범위와 비용

Groq 계정의 정확한 무료 한도와 과금 정책은 콘솔에서 확인하세요. 이 클라이언트는 세션당 요청 시작 간격을 최소 4초로 제한하지만, 여러 회의의 합산 요청을 제어하는 조직 전체 한도 장치는 아닙니다. 4초마다 요청하면 시간당 약 900회이므로 긴 회의에서는 요청 수 한도에도 주의해야 합니다. 짧은 조각의 비용을 실제 음성 길이만으로 계산하면 요청당 최소 과금 정책을 놓칠 수 있습니다.

앱은 한도 응답(429)에 자동 재시도하거나 다른 업체로 전환하지 않습니다. **API 키만으로 Free 플랜 여부를 검증하거나 무료를 보장할 수 없습니다.** Groq 계정을 유료 플랜으로 전환하면 같은 키로 과금될 수 있습니다.

DeepSeek API는 별도 사용량 과금 서비스입니다. 키 보유가 무료 사용을 의미하지 않습니다. 계정 잔액과 사용량을 확인하세요. API 연결 오류에 대해 자동 재시도·다른 업체 전환을 하지 않습니다.

## 첫 시험

실제 사내 문서 대신 테스트용 문장으로 시작합니다. 마이크 선택·입력 수준 확인 → Groq 전송 동의 → 짧은 발화 전사 확인 → DeepSeek 전송 동의 → 질문과 근거 확인 순서입니다. 연결 상태의 '키 설정됨'은 실제 API 인증·잔액·전사 성공을 의미하지 않습니다.

키가 없는 상태에서는 외부 호출 성공을 검증할 수 없습니다. 로컬 모의 응답 테스트와 실제 서비스 품질을 구분합니다. 조직 회의에 적용하기 전 음성과 문서의 외부 전송에 대한 조직 정책 및 참석자 동의를 확인하세요.

## 다른 전사 방식

Azure와 로컬 전사 코드는 대안으로 유지하지만 자동으로 사용하지 않습니다. Azure를 선택하려면 `STT_PROVIDER=azure`, 실제 F0 리소스의 키·리전·`AZURE_SPEECH_TIER=F0` 설정이 필요합니다. Groq 기본 구성에서는 Azure 가입이나 키가 필요하지 않습니다.
